Self-Attention 2D
-----------------

The geometry of self-attention in two dimensions: the query, key and value projections of two input vectors and the attention outputs they produce.

.. image:: /_static/screenshots/book2/ch13_self_attention_2d.webp
   :alt: Self-Attention 2D demo window
   :width: 100%

**How to use it**

Click and drag the tips of p(1) or p(2) to move the input vectors.

Adjust W^Q, W^K, W^V rotation angles with sliders.

The dashed arrows show attention output vectors.

**Controls**

- W^Q angle (slider)
- W^K angle (slider)
- W^V angle (slider)
- Reset (button)

**Source:** ``nndesigndemos/book2/chapter13/Self_attention_2d.py``

.. _book2-ch13-self_attention_3d:

Self-Attention 3D
-----------------

Shows the attention output as a surface over one input vector, to see how the output responds as that input moves while the other is fixed.

.. image:: /_static/screenshots/book2/ch13_self_attention_3d.webp
   :alt: Self-Attention 3D demo window
   :width: 100%

**How to use it**

Two 3D surfaces show how o(n) varies as a function of p(1).

Drag p(2) in the 2D panel.

Select o(1) or o(2) with the radio buttons.

**Controls**

- W^Q angle (slider)
- W^K angle (slider)
- W^V angle (slider)
- Reset (button)

**Source:** ``nndesigndemos/book2/chapter13/Self_attention_3d.py``
