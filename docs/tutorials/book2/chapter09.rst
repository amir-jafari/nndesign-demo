Linearized Network Response
---------------------------

Post-training analysis of a trained network: linearizing the response around a chosen input point shows the local gradient, or sensitivity, and the tangent-plane approximation at that point.

.. image:: /_static/screenshots/book2/ch09_linearized_network_response.webp
   :alt: Linearized Network Response demo window
   :width: 100%

**How to use it**

Click a location in the left graph where you want to linearize the network response.
