Gradient Descent
----------------

Gradient descent on an error surface, drawn on the surface itself. Revisits steepest descent from Chapter 9 of the first book as the starting point for training deep networks.

.. image:: /_static/screenshots/book2/ch03_gradient_descent.webp
   :alt: Gradient Descent demo window
   :width: 100%

**How to use it**

Click anywhere on the graph to start an initial guess. Then the steepest descent trajectory will be shown.

Modify the learning rate by moving the slide bar.

Experiment with different initial guesses and learning rates.

- Learning rate (slider)

.. _book2-ch03-stochastic_gradient_descent:

Stochastic Gradient Descent
---------------------------

Stochastic gradient descent estimates the gradient from a minibatch, so each step is cheaper but noisier. The trajectory shows the random walk around the path of full gradient descent.

.. _book2-ch03-gradient_descent_vs_adam:

Gradient Descent vs Adam
------------------------

Compares plain gradient descent with Adam, which adapts the step size of every parameter from running estimates of the gradient's mean and variance, on the same training task.

.. image:: /_static/screenshots/book2/ch03_gradient_descent_vs_adam.webp
   :alt: Gradient Descent vs Adam demo window
   :width: 100%

**How to use it**

Two identical networks learn the same task, one using gradient descent, one using Adam. Press Train to see which one reduces F(x) faster.
