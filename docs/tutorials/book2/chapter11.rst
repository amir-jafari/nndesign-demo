Sequence Averaging Network
--------------------------

A linear network with a tapped delay line that averages consecutive inputs, the simplest example of processing a sequence one time step at a time.

.. image:: /_static/screenshots/book2/ch11_sequence_averaging_network.webp
   :alt: Sequence Averaging Network demo window
   :width: 100%

**How to use it**

Change input sequence by entering values in input fields.

Click [Update] to apply your changes.

Click [Set Default] to restore original values.

**Controls**

- w1 (slider)
- w2 (slider)
- Update (button)
- Set Default (button)
- Enable Animation (checkbox)
- Pause (button)

Impulse Response
----------------

Shows how the pole locations of a linear recurrent network determine its impulse response: decaying, oscillating or unstable.

.. image:: /_static/screenshots/book2/ch11_impulse_response.webp
   :alt: Impulse Response demo window

**How to use it**
