.. _book2-ch05-learning_scheduler:

Learning Scheduler
------------------

A learning rate schedule with linear warm-up, a plateau and geometric decay, applied to gradient descent on a linear regression problem, to show how the schedule changes convergence.

.. image:: /_static/screenshots/book2/ch05_learning_scheduler.webp
   :alt: Learning Scheduler demo window
   :width: 100%

**How to use it**

Adjust the learning rate scheduler parameters using the sliders.

The demo shows how different learning rate schedules affect the convergence of gradient descent on a linear regression problem.

**Controls**

- lr_0 (slider)
- lr_0_steps (slider)
- lr_max (slider)
- lr_max_steps (slider)
- lr_decay (slider)
- Enable Animation (checkbox)
- Train (button)
- Pause (button)
- New Random Data (button)
