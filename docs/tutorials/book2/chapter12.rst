Parity Network
--------------

A nonlinear recurrent network that computes the parity of a bit sequence, a task that requires remembering state from earlier time steps.

.. image:: /_static/screenshots/book2/ch12_parity_network.webp
   :alt: Parity Network demo window
   :width: 100%

**How to use it**

Click input buttons to toggle bits (0/1).

The output updates automatically.

Enable animation to see step-by-step execution.

Click [Set Default] to restore original values.

**Controls**

- Enable Animation (checkbox)
- Pause (button)
- Set Default (button)

.. _book2-ch12-constant_error_carousel:

Constant Error Carousel
-----------------------

The constant error carousel at the heart of the LSTM: a linear unit with unit self-feedback keeps information, and gradients, from fading over long sequences.

.. image:: /_static/screenshots/book2/ch12_constant_error_carousel.webp
   :alt: Constant Error Carousel demo window
   :width: 100%

**How to use it**

Change input sequence by entering values in input fields.

Click [Update] to apply your changes.

Click [Set Default] to restore original values.

CEC uses LW1,1 = 1 and linear transfer function to maintain long memory.

**Controls**

- Update (button)
- Set Default (button)
- Enable Animation (checkbox)
- Pause (button)

**Source:** ``nndesigndemos/book2/chapter12/constant_error_carousel/Constant_error_carousel.py``

.. _book2-ch12-gated_cec:

Gated CEC
---------

Adds input and feedback gates to the constant error carousel, showing how the gates decide what enters the memory and how much of it is kept.

.. image:: /_static/screenshots/book2/ch12_gated_cec.webp
   :alt: Gated CEC demo window
   :width: 100%

**How to use it**

Click buttons to toggle gates between 0 and 1.

Input gate g^i(t) controls how much input enters memory.

Feedback gate g^f(t) controls how much previous state is retained.

Enable animation to see step-by-step execution.

**Controls**

- Enable Animation (checkbox)
- Pause (button)
- Set Default (button)

**Source:** ``nndesigndemos/book2/chapter12/gated_cec/GatedCECDemo.py``
