Scaling
-------

Shows how input scaling and batch normalization change the distributions of inputs, net inputs and outputs inside a deep network, and why keeping those distributions well behaved makes training easier.

.. image:: /_static/screenshots/book2/ch04_scaling.webp
   :alt: Scaling demo window
   :width: 100%

**How to use it**

Choose a initialization scheme and whether to use BatchNorm or not.

The distribution of input, net input and output is shown on the left.

**Controls**

- Number of examples (slider)
- Input distribution (menu)
- Weights init (menu)
- Activation function (menu)
- Use Batch Norm (checkbox)
- Random (button)

.. _book2-ch04-dropout:

Dropout
-------

Dropout as a regularizer: randomly disabling hidden neurons during training on noisy data, compared with the early-stopping and regularization demos of the first book.

.. image:: /_static/screenshots/book2/ch04_dropout.webp
   :alt: Dropout demo window
   :width: 100%

**How to use it**

Use sliders to change the dropout value, the number of neurons in the hidden layer, the Noise Standard Deviation of the training points.

Use the checkbox to turn off and turn on the dropout.

Click [Train] to train on the training points.

**Controls**

- No Dropout (checkbox)
- Dropout value (slider)
- Number of neurons (slider)
- Noise standard deviation (slider)
- Pause (button)

**Source:** ``nndesigndemos/book2/chapter4/Dropout.py``
