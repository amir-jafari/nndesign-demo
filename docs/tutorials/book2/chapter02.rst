.. _book2-ch02-poslin_network_function:

Poslin Network Function
-----------------------

A multilayer network built from poslin (ReLU) neurons. Each hidden neuron contributes one piecewise-linear bend, and the demo shows how the weights and biases place those bends to build up the network function.

.. image:: /_static/screenshots/book2/ch02_poslin_network_function.webp
   :alt: Poslin Network Function demo window
   :width: 100%

**How to use it**

Alter the network's parameters by dragging the slide bars.

Choose the output transfer function f below.

Click on [Random] to set each parameter to a random value.

**Controls**

- f (menu)
- Random (button)
- W1(1,1) (slider)
- W1(2,1) (slider)
- b1(1) (slider)
- b1(2) (slider)
- W2(1,1) (slider)
- W2(1,2) (slider)
- b2 (slider)

**Source:** ``nndesigndemos/book2/chapter2/Poslin_network_function.py``

Poslin Decision Regions
-----------------------

Shows how a poslin network with two inputs divides the input plane into regions, each hidden neuron adding one linear fold to the response.

.. image:: /_static/screenshots/book2/ch02_poslin_decision_regions.webp
   :alt: Poslin Decision Regions demo window
   :width: 100%

**How to use it**

Alter the network's parameters by dragging the slide bars.

The plot updates as you drag.

.. _book2-ch02-cascaded_function:

Cascaded Function
-----------------

Shows what happens when layers are cascaded: the output of one hidden function becomes the input of the next, so a few layers of a simple function compose into a much more complex one.

.. image:: /_static/screenshots/book2/ch02_cascaded_function.webp
   :alt: Cascaded Function demo window
   :width: 100%

**How to use it**

Experiment with the hidden function and number of layers using the dropdown menus below.

Set the input value to 0 in order to start the animation, or control it manually by moving the slider.

**Controls**

- f (menu)
- Number of layers (menu)
- Input value (slider)
