Convolution Networks demo
-------------------------

Shows how a convolution layer slides a kernel over its input, and how input size, kernel size, stride and padding determine the size of the output feature map.

.. image:: /_static/screenshots/book2/ch08_convolution_networks_demo.webp
   :alt: Convolution Networks demo demo window
   :width: 100%

**How to use it**

Change the input shape, input size, kernel size, and stride below.

Use checkboxs to change padding and value status.

Click input or kernel images to change the input pattern or kernel pattern.

**Controls**

- Input shape (menu)
- Input size (slider)
- Kernel size (slider)
- Stride(s) (slider)
- Padding (checkbox)
- Show values (checkbox)
- Enable Animation (checkbox)
- Pause (button)
