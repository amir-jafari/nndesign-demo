.. _book1-ch04-decision_boundaries:

Decision boundaries
-------------------

Shows the geometry behind a perceptron: the decision boundary is a line perpendicular to the weight vector, offset by the bias. Moving the boundary by hand shows which weight and bias values produce it.

.. image:: /_static/screenshots/book1/ch04_decision_boundaries.webp
   :alt: Decision boundaries demo window
   :width: 100%

**How to use it**

Move the perceptron decision boundary by dragging the stars.

Try to divide the points so that none of them are red.

Left-click on the plot to add a positive class.

Right-click to add a negative class.

The weight and bias will take on values associated with the chosen decision boundary.

**Controls**

- Undo Last Mouse Click (button)
- Clear Data (button)

.. _book1-ch04-perceptron_rule:

Perceptron rule
---------------

Demonstrates the perceptron learning rule, which adds or subtracts input vectors to the weights until every training point falls on the correct side of the boundary. It converges whenever the classes are linearly separable.

.. image:: /_static/screenshots/book1/ch04_perceptron_rule.webp
   :alt: Perceptron rule demo window
   :width: 100%

**How to use it**

Left-click on the plot to add a positive class.

Right-click to add a negative class.

Click [Learn] to apply the perceptron rule to a single vector.

Click [Train] to apply the rule to all the vectors for n_epochs.

Click [Random] to initialize parameters randomly.

**Controls**

- Epochs to Run (menu)
- Use Bias (menu)
- Train (button)
- Learn (button)
- Random (button)
- Undo Last Mouse Click (button)
- Clear Data (button)
