FIR Network
-----------

A finite impulse response (FIR) network: a layer fed by a tapped delay line of the input. Shows how the weights shape its response to sinusoidal, square and other input sequences.

.. image:: /_static/screenshots/book1/ch14_fir_network.webp
   :alt: FIR Network demo window
   :width: 100%

**How to use it**

Select the input and frequency to the FIR network.

Use the sliders to alter the network weights.

**Controls**

- Autoscale (menu)
- f (menu)
- frequency (menu)
- iW(0) (slider)
- iW(1) (slider)
- iW(2) (slider)

.. _book1-ch14-iir_network:

IIR Network
-----------

An infinite impulse response (IIR) network, which feeds its own delayed output back to the input, so the response depends on previous outputs as well as previous inputs.

.. image:: /_static/screenshots/book1/ch14_iir_network.webp

.. _book1-ch14-dynamic_derivatives:

Dynamic Derivatives
-------------------

Compares static and dynamic derivatives in a recurrent network. The dynamic derivative includes the effect of a weight change propagating around the feedback loop over time, which is what dynamic backpropagation must compute.

.. image:: /_static/screenshots/book1/ch14_dynamic_derivatives.webp
   :alt: Dynamic Derivatives demo window
   :width: 100%

**How to use it**

Original responses - black dots. Incremental responses - blue crosses. Total derivatives - blue diamonds. Static derivatives - black squares.

Select the input and frequency to the IIR network.

Use the sliders to alter the network weights.

**Controls**

- f (menu)
- frequency (menu)
- iW(0) (slider)
- lW(1) (slider)

**Source:** ``nndesigndemos/book1/chapter14/Dynamic_derivatives.py``

.. _book1-ch14-recurrent_network_training:

Recurrent Network Training
--------------------------

Shows the training of a recurrent network with dynamic backpropagation, and the spurious valleys in the error surface that make recurrent networks hard to train.

.. image:: /_static/screenshots/book1/ch14_recurrent_network_training.webp
   :alt: Recurrent Network Training demo window
   :width: 100%

**How to use it**

Show the change in weight values due to the training of a recurrent network.

Click on the contour plot to select the initial weight values.

The weights will be updated and the network output will be shown at the upper left figure.
