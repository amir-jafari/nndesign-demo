One-input Neuron
----------------

The simplest building block of every network in the book: one neuron with one scalar input. It shows how the weight scales the input, the bias shifts it, and the transfer function shapes the result into the output a = f(wp + b).

.. image:: /_static/screenshots/book1/ch02_one_input_neuron.webp
   :alt: One-input Neuron demo window
   :width: 100%

**How to use it**

Alter the weight, bias and input by moving the sliders.

Pick the transfer function with the f menu.

Watch the change to the neuron function and its output.

**Controls**

- w (slider)
- b (slider)
- f (menu)

**Source:** ``nndesigndemos/book1/chapter2/One_input_neuron.py``

.. _book1-ch02-two_input_neuron:

Two-input Neuron
----------------

Extends the single neuron to two inputs, so you can see how the net input n = w1 p1 + w2 p2 + b combines several inputs before the transfer function. This is the step toward layers described by weight matrices.

.. image:: /_static/screenshots/book1/ch02_two_input_neuron.webp
   :alt: Two-input Neuron demo window
   :width: 100%

**How to use it**

Alter the input values by moving the sliders.

Alter the weight and bias in the same way. Use the menu to pick a transfer function.

The net input and the output will respond to each change.

**Controls**

- f (menu)
- p1 (slider)
- w1 (slider)
- p2 (slider)
- w2 (slider)
- b (slider)
- n (slider)
- a (slider)

**Source:** ``nndesigndemos/book1/chapter2/Two_input_neuron.py``
