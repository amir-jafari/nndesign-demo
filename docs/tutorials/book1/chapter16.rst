Competitive Classification
--------------------------

The fruit-sorting problem solved with a competitive layer: the neurons compete and the one whose weight vector is closest to the input wins.

.. image:: /_static/screenshots/book1/ch16_competitive_classification.webp
   :alt: Competitive Classification demo window
   :width: 100%

**How to use it**

Click [Go] to send a fruit down the belt to be classified by the competitive layer.

The calculations for the layer will appear below.

.. _book1-ch16-competitive_learning:

Competitive Learning
--------------------

Competitive learning with the Kohonen rule: the winning neuron's weight vector moves toward each input, so the prototypes end up clustering the data.

.. image:: /_static/screenshots/book1/ch16_competitive_learning.webp
   :alt: Competitive Learning demo window
   :width: 100%

**How to use it**

Click on the plot to add new input vectors.

Click on the weight vectors and drag the mouse to move them.

Click [Learn] to present one input.

Click [Train] to present all inputs.

**Controls**

- Learning Rate (slider)
- Learn (button)
- Train (button)
- Random (button)
- Speed (slider)

**Source:** ``nndesigndemos/book1/chapter16/Competitive_learning.py``

.. _book1-ch16-1_d_feature_map:

1-D Feature Map
---------------

A one-dimensional self-organizing feature map. Neighbouring neurons learn together, so their weight vectors arrange themselves along a chain that follows the distribution of the inputs.

.. image:: /_static/screenshots/book1/ch16_1_d_feature_map.webp
   :alt: 1-D Feature Map demo window
   :width: 100%

**How to use it**

Click [Train] to present 500 vectors to the feature map.

Several clicks are required to obtain a stable network.

Click [Reset] to start over if the network develops a twist.

**Controls**

- Learning Rate (slider)
- Neighborhood (slider)
- Train (button)
- Reset (button)

**Source:** ``nndesigndemos/book1/chapter16/OneD_feature_map.py``

.. _book1-ch16-lvq_1:

LVQ 1
-----

Learning vector quantization (LVQ1), a competitive network trained with supervision: the winning prototype moves toward the input if it has the right class and away from it if it does not.

.. image:: /_static/screenshots/book1/ch16_lvq_1.webp
   :alt: LVQ 1 demo window
   :width: 100%

**How to use it**

Click [Learn] to apply the LVQ1 rule once.

Click [Train] to apply it on all the inputs.

Click [Random] to get random weights.

Left-click on the plot to add a positive class.

Right-click to add a negative class.

Misclassifications are shown in red.

**Controls**

- Learn (button)
- Train (button)
- Random (button)
- Undo Last Mouse Click (button)
- Clear Data (button)

**Source:** ``nndesigndemos/book1/chapter16/Lvq1.py``
