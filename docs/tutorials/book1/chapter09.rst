Steepest descent for Quadratic
------------------------------

Steepest descent on a quadratic function. Shows how the learning rate decides whether the trajectory converges smoothly, oscillates or diverges, with the stability limit set by the largest eigenvalue of the Hessian.

.. image:: /_static/screenshots/book1/ch09_steepest_descent_for_quadratic.webp
   :alt: Steepest descent for Quadratic demo window
   :width: 100%

**How to use it**

Click anywhere on the graph to start an initial guess.Then the steepest descent trajectory will be shown.

Modify the learning rate by moving the slide bar.

Experiment with different initial guesses and learning rates.

**Controls**

- lr (slider)

.. _book1-ch09-method_comparison:

Method comparison
-----------------

Compares steepest descent with the conjugate gradient method on the same quadratic function, both using a line search, to show how conjugate gradient reaches the minimum in far fewer steps.

.. image:: /_static/screenshots/book1/ch09_method_comparison.webp
   :alt: Method comparison demo window
   :width: 100%

**How to use it**

Click in either graph to start a search point.

Then watch the two algorithms attempt to find the minima.

The two alrorithms are:

- Steepest Descent using line search.

- Conjugate Gradient using line search.

**Source:** ``nndesigndemos/book1/chapter9/Comparison_of_methods.py``

.. _book1-ch09-newton_s_method:

Newton's method
---------------

Illustrates Newton's method, which minimizes the second-order Taylor approximation at each step. It finds the minimum of a quadratic in one step but can be misled on functions that are not quadratic.

.. image:: /_static/screenshots/book1/ch09_newton_s_method.webp
   :alt: Newton's method demo window
   :width: 100%

**How to use it**

Click anywhere on the graph to start an initial guess.

Then the Newton's method trajectory will be shown.

The bottom graph shows the quadratic approximation of the function at the initial point.

**Source:** ``nndesigndemos/book1/chapter9/Newtons_method.py``
