.. _book1-ch15-unsupervised_hebb:

Unsupervised Hebb
-----------------

Unsupervised Hebbian learning on the banana-recognition network: a weight grows when its input and the neuron's output are active together, so the network learns to respond to a stimulus that keeps accompanying one it already recognizes.

.. image:: /_static/screenshots/book1/ch15_unsupervised_hebb.webp
   :alt: Unsupervised Hebb demo window
   :width: 100%

**How to use it**

Click [Fruit] to send a fruit down the belt to be recognized.

Click [Update] to apply the Hebb rule.

When the lower weight is >0.5, the network will recognize bananas with the first scanner off.

**Controls**

- First Scanner (checkbox)
- Fruit (button)

**Source:** ``nndesigndemos/book1/chapter15/Unsupervised_hebb_v3.py``

.. _book1-ch15-effects_of_decay_rate:

Effects of Decay Rate
---------------------

Shows how a decay term in the Hebb rule keeps the weights bounded. The learning rate and the decay rate together set the maximum weight and how quickly the network forgets.

.. image:: /_static/screenshots/book1/ch15_effects_of_decay_rate.webp
   :alt: Effects of Decay Rate demo window
   :width: 100%

**How to use it**

Use the slider bars to adjust learning and decay rates.

Click [Clear] to remove old responses.

Click [Random] to get random parameters.

**Controls**

- Learning Rate (slider)
- Decay Rate (slider)
- Clear (button)
- Random (button)

**Source:** ``nndesigndemos/book1/chapter15/Effects_of_decay_rate.py``

.. _book1-ch15-hebb_with_decay:

Hebb with Decay
---------------

The banana network again, now with weight decay: the weight stops growing at a limit and shrinks when the association is not reinforced.

.. image:: /_static/screenshots/book1/ch15_hebb_with_decay.webp
   :alt: Hebb with Decay demo window
   :width: 100%

**How to use it**

Click [Fruit] to send a fruit down the belt to be recognized.

Click [Update] to apply the Hebb rule.

Because of weight decay, the weight will never exceed a value of 2.0.

**Controls**

- First Scanner (checkbox)
- Fruit (button)

**Source:** ``nndesigndemos/book1/chapter15/Hebb_with_decay_v3.py``

.. _book1-ch15-graphical_instar:

Graphical Instar
----------------

A geometric view of the instar rule: when the neuron is active, the weight vector moves toward the input vector by a fraction set by the learning rate.

.. image:: /_static/screenshots/book1/ch15_graphical_instar.webp
   :alt: Graphical Instar demo window
   :width: 100%

**How to use it**

Click on the top graph to change the green weight vector.

Click on the bottom graph to change the red input vector.

Use the slider to change the learning rate.

The change in the weight vector is shown with a black arrow.

Click [Update] to make the change.

**Controls**

- Learning Rate (slider)
- Update (button)

**Source:** ``nndesigndemos/book1/chapter15/Graphical_instar.py``

Outstar
-------

Demonstrates the outstar rule, which learns to recall a pattern. After the network has seen several pineapples with both scanners on, it reproduces their measurements from the identifying signal alone.

.. image:: /_static/screenshots/book1/ch15_outstar.webp
   :alt: Outstar demo window
   :width: 100%

**How to use it**

Click [Fruit] to send a fruit down the belt to be recognized.

Click [Update] to apply the Hebb rule.

Once the network has seen several pineapples with both scanners, it will recall their measurements with the first scanner off.
