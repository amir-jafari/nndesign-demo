.. _book1-ch08-taylor_series_1:

Taylor series #1
----------------

Shows how a Taylor series approximates a function near a point, using the zeroth-, first- and second-order approximations of the cosine. These local approximations are the tool for analysing performance surfaces.

.. image:: /_static/screenshots/book1/ch08_taylor_series_1.webp
   :alt: Taylor series #1 demo window
   :width: 100%

**How to use it**

Click on the top graph to create a Taylor series approximation of the cosine function.

Click on the checkboxes to turn various orders of approximation on and off.

**Controls**

- Function (checkbox)
- Order 0 (checkbox)
- Order 1 (checkbox)
- Order 2 (checkbox)
- Order 3 (checkbox)
- Order 4 (checkbox)

.. _book1-ch08-directional_derivatives:

Directional derivatives
-----------------------

Illustrates the directional derivative, the slope of a performance surface in a chosen direction, which is computed from the gradient and the direction vector.

.. image:: /_static/screenshots/book1/ch08_directional_derivatives.webp
   :alt: Directional derivatives demo window
   :width: 100%

**How to use it**

To measure a directional derivative click on the graph and move the cursor.

The directional derivative is taken at the point you clicked in the direction of the current cursor position.

Click again to choose a new point where you want to measure the directional derivative.

**Controls**

- Directional Derivative (slider)

**Source:** ``nndesigndemos/book1/chapter8/Directional_derivatives.py``

.. _book1-ch08-quadratic_function:

Quadratic function
------------------

Shows the quadratic function F(x) = ½ xᵀAx + dᵀx + c. Its shape, a bowl, a saddle or a valley, is decided by the eigenvalues and eigenvectors of the Hessian matrix A.

.. image:: /_static/screenshots/book1/ch08_quadratic_function.webp
   :alt: Quadratic function demo window
   :width: 100%

**How to use it**

Change the values of the Hessian matrix A, the vector d, and the constant c. Then click [Update] to see the new function.

Note that the Hessian matrix will always be symmetric.

You can rotate the 3D plots by clicking and dragging in the plot window.

**Controls**

- 1.5 (input box)
- -0.7 (input box)
- 1.0 (input box)
- 0.35 (input box)
- 0.25 (input box)
- Update (button)

**Source:** ``nndesigndemos/book1/chapter8/Quadratic_function.py``
