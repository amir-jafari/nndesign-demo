Steepest Descent #1
-------------------

Basic backpropagation seen as steepest descent on the error surface of a 1-2-1 network, with the surface shown in 3D. Flat regions and local minima explain why plain backpropagation can be slow.

   :alt: Steepest Descent #1 demo window
   :width: 100%

**How to use it**

The corresponding error surface and contour are shown below.

Click in the contour graph to start the steepest descent algorithm.

------------------

.. _book1-ch12-marquardt_step:

Marquardt Step
--------------

Illustrates a single Levenberg-Marquardt step: as the parameter mu changes, the step interpolates between the Gauss-Newton step and a small step in the gradient direction.

.. image:: /_static/screenshots/book1/ch12_marquardt_step.webp
   :alt: Marquardt Step demo window
   :width: 100%

**How to use it**

Click on the contour plot to do a single step of the Marquardt learning algorithm.

The black arrow indicates the Gauss-Newton step.

The red arrow indicates the gradient direction.

The blue line indicates the Marquardt step as mu is ajusted.

**Controls**

- Pair of parameters (menu)

**Source:** ``nndesigndemos/book1/chapter12/Marquardt_step.py``
