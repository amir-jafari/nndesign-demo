Perceptron classification
-------------------------

The apple-versus-orange sorting problem of Chapter 3 solved with a single-neuron perceptron. The hard-limit neuron separates the two fruit classes with a plane in the three-dimensional space of shape, texture and weight measurements.

   :alt: Perceptron classification demo window
   :width: 100%

**How to use it**

.. _book1-ch03-hamming_classification:

Hamming classification
----------------------

The same fruit problem solved by a Hamming network: a feedforward layer measures how close the input is to each stored prototype, then a recurrent competitive layer lets the closest prototype win.

.. _book1-ch03-hopfield_classification:

Hopfield classification
-----------------------

The same problem solved with a Hopfield network, a recurrent network whose state is iterated until it settles on the stored prototype that is nearest to the input.
