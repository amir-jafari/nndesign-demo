Hopfield Network
----------------

The continuous Hopfield network as a dynamical system: the state moves downhill on the Lyapunov (energy) function toward stable points that act as stored memories.

.. image:: /_static/screenshots/book1/ch21_hopfield_network.webp
   :alt: Hopfield Network demo window
   :width: 100%

**How to use it**

Click in the left graph to simulate the Hopfield Network.

Change the weights, biases and gain. Then click [Update] to change the network.

**Controls**

- 0 (input box)
- 1 (input box)
- Finite Value Gain (slider)
- Gain (menu)
- Update (button)
