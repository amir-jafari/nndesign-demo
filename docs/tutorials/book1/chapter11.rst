.. _book1-ch11-network_function:

Network Function
----------------

Shows the function computed by a 1-2-1 network, two log-sigmoid hidden neurons feeding a linear output, and how each weight and bias reshapes the response. This is the foundation of function approximation with multilayer networks.

.. image:: /_static/screenshots/book1/ch11_network_function.webp
   :alt: Network Function demo window
   :width: 100%

**How to use it**

Alter the network's parameters by dragging the slide bars.

Choose the output transfer function f below.

Click on [Random] to set each parameter to a random value.

**Controls**

- f (menu)
- Random (button)
- W1(1,1) (slider)
- W1(2,1) (slider)
- b1(1) (slider)
- b1(2) (slider)
- W2(1,1) (slider)
- W2(1,2) (slider)
- b2 (slider)

**Source:** ``nndesigndemos/book1/chapter11/Network_function.py``

.. _book1-ch11-function_approximation:

Function Approximation
----------------------

Trains a two-layer network with backpropagation to fit a target function. Shows how the number of hidden neurons limits how complex a function the network can approximate.

.. image:: /_static/screenshots/book1/ch11_function_approximation.webp
   :alt: Function Approximation demo window
   :width: 100%

**How to use it**

Click the [Train] button to train the logsig-linear network on the blue function.

Use the slide bars to choose the number of neurons and the difficulty of the blue function.

**Controls**

- Train (button)

**Source:** ``nndesigndemos/book1/chapter11/Function_approximation.py``

.. _book1-ch11-generalization:

Generalization
--------------

Trains the same network on noisy data points to show how network size affects generalization: too few neurons underfit, too many fit the noise.

.. image:: /_static/screenshots/book1/ch11_generalization.webp
   :alt: Generalization demo window
   :width: 100%

**How to use it**

Click the [Train] button to train the logsig-linear network on the data points.

Use the slide bars to choose the number of neurons and the difficulty of the data points.

**Controls**

- Animation Delay (slider)
- Train (button)
- Pause (button)
