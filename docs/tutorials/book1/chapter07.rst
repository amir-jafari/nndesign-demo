Supervised Hebb
---------------

Demonstrates supervised Hebbian learning on a pattern-recognition task. The Hebb rule or the pseudoinverse rule builds the weight matrix from the target patterns, and the resulting network reconstructs a corrupted test pattern.

.. image:: /_static/screenshots/book1/ch07_supervised_hebb.webp
   :alt: Supervised Hebb demo window
   :width: 100%

**How to use it**

Click on the green grids to define target patterns.

Click on the gray grid to define a test pattern.

Select a rule to calculate the network weights.

**Controls**

- Learning Rule (menu)
