Adaptive noise cancellation
---------------------------

The classic ADALINE application: an adaptive filter trained with the LMS algorithm learns to predict the noise contaminating a signal, so the noise can be subtracted and the original signal recovered.

.. image:: /_static/screenshots/book1/ch10_adaptive_noise_cancellation.webp
   :alt: Adaptive noise cancellation demo window
   :width: 100%

**How to use it**

Click on the bottom contour plot to change the initial weights.

Use the sliders to alter the learning rate and momentum.

You can choose to display the original and estimated signals or their difference.

**Controls**

- lr (slider)

.. _book1-ch10-eeg_noise_cancellation:

EEG noise cancellation
----------------------

Applies LMS noise cancellation to an electroencephalogram (EEG) contaminated by power-line interference, a realistic use of the adaptive linear network.

.. image:: /_static/screenshots/book1/ch10_eeg_noise_cancellation.webp
   :alt: EEG noise cancellation demo window
   :width: 100%

**How to use it**

An EEG signal has been contaminated with noise.

An adaptive linear network is used to remove the noise.

Use the sliders to set the learning rate and the number of delays.

You can choose to display the original and estimated signals or their difference.

**Controls**

- lr (slider)
- Delays (slider)

**Source:** ``nndesigndemos/book1/chapter10/EEG_noise_cancellation.py``

.. _book1-ch10-linear_classification:

Linear classification
---------------------

Shows an ADALINE trained with the LMS algorithm as a pattern classifier, and how its output meter responds as the input pattern is edited one pixel at a time.

.. image:: /_static/screenshots/book1/ch10_linear_classification.webp
   :alt: Linear classification demo window
   :width: 100%

**How to use it**

Edit the RED grid and watch the output meter respond to the new inputs.

Edit the GREEN grids and then click [Train] to study a different problem.

Use GREEN patterns as inputs by clicking the arrow bottoms.

**Controls**

- -> (button)
- Train (button)
