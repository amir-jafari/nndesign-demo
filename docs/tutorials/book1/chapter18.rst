.. _book1-ch18-leaky_integrator:

Leaky Integrator
----------------

The leaky integrator, the basic building block of Grossberg's networks: its output follows the input with a time constant, modelling the continuous-time response of a neuron.

.. image:: /_static/screenshots/book1/ch18_leaky_integrator.webp
   :alt: Leaky Integrator demo window
   :width: 100%

**How to use it**

Use the slide bars to adjust the input and the time constant (eps) to the leaky integrator.

Click [Clear] to remove old responses.

Click [Random] for random patterns.

**Controls**

- Input p (slider)
- Time Constant (slider)
- Clear (button)
- Random (button)

**Source:** ``nndesigndemos/book1/chapter18/Leaky_integrator.py``

.. _book1-ch18-shunting_network:

Shunting Network
----------------

The shunting model, in which excitatory and inhibitory inputs multiply the state, so the response stays bounded no matter how large the inputs become.

.. image:: /_static/screenshots/book1/ch18_shunting_network.webp
   :alt: Shunting Network demo window
   :width: 100%

**How to use it**

Use the slide bars to adjust the inputs, biases and the time constant (eps).

Click [Clear] to remove old responses.

Grossberg Layer 1
-----------------

Layer 1 of the Grossberg network. Its on-center/off-surround connections normalize the input pattern, so the layer responds to relative rather than absolute intensities.

.. image:: /_static/screenshots/book1/ch18_grossberg_layer_1.webp
   :alt: Grossberg Layer 1 demo window
   :width: 100%

**How to use it**

Click [Clear] to remove old responses.
