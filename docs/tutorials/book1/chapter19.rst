ART1 Layer 1
------------

Layer 1 of ART1, which compares the input pattern with the expectation sent down from Layer 2 and passes on only where the two agree.

.. image:: /_static/screenshots/book1/ch19_art1_layer_1.webp
   :alt: ART1 Layer 1 demo window
   :width: 100%

**How to use it**

Adjust the inputs, biases and weights. Then click [Update] to see the layer respond.

n1(1) is red, n1(2) is green.

Click [Clear] to remove old responses.

**Controls**

- Input p(1) (slider)
- Input p(2) (slider)
- Bias b+ (slider)
- Bias b- (slider)
- 1 (input box)
- 0 (input box)
- Clear (button)
- Update (button)
