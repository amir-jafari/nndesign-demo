.. _book1-ch17-network_function_radial:

Network Function Radial
-----------------------

Shows the function computed by a radial basis network with two Gaussian hidden neurons, and how the centers, widths and output weights shape it. Compare it with the sigmoid network of Chapter 11.

.. image:: /_static/screenshots/book1/ch17_network_function_radial.webp
   :alt: Network Function Radial demo window
   :width: 100%

**How to use it**

Alter the network's parameters by dragging the slide bars.

Click on [Random] to set each parameter to a random value.

**Controls**

- W1(1,1) (slider)
- W1(2,1) (slider)
- b1(1) (slider)
- b1(2) (slider)
- W2(1,1) (slider)
- W2(1,2) (slider)
- b2 (slider)
- Random (button)

Pattern Classification

Shows a radial basis network as a two-dimensional classifier. Each hidden neuron carves out a region around its center, visible in the 3D response surface.

.. _book1-ch17-linear_least_squares:

Linear Least Squares
--------------------

Trains only the output layer of a radial basis network with linear least squares, after fixing the centers and spreads of the basis functions.

.. image:: /_static/screenshots/book1/ch17_linear_least_squares.webp
   :alt: Linear Least Squares demo window
   :width: 100%

**How to use it**

Basis functions are spaced evenly.

You can change the first center location and the bias. The automatic bias will produce overlap at 0.5.

The function is shown in blue and the network response in red.

**Controls**

- Auto Bias (menu)
- W1(1,1) (slider)
- b (slider)
- Hidden Neurons (slider)
- Number of Points (slider)
- Regularization (slider)
- Stdev Noise (slider)
- Function Frequency (slider)
- Function Phase (slider)

**Source:** ``nndesigndemos/book1/chapter17/Linear_least_squares.py``

.. _book1-ch17-orthogonal_least_squares:

Orthogonal Least Squares
------------------------

Shows orthogonal least squares, which picks the most useful basis centers from the training points one at a time, growing the hidden layer until the error is small enough.

.. image:: /_static/screenshots/book1/ch17_orthogonal_least_squares.webp
   :alt: Orthogonal Least Squares demo window
   :width: 100%

**How to use it**

Use the slide bars to choose the network or function values.

Click [Add Neuron] to increase the size of Hidden Layer.

The function is shown in blue and the network response in red.

**Controls**

- Auto Bias (menu)
- Number of Points (slider)
- b (slider)
- Stdev Noise (slider)
- Function Frequency (slider)
- Function Phase (slider)
- Add Neuron (button)
- Reset (button)

**Source:** ``nndesigndemos/book1/chapter17/Orthogonal_least_squares.py``

.. _book1-ch17-non_linear_optimization:

Non Linear Optimization
-----------------------

Trains all parameters of a radial basis network, including centers and widths, with gradient-based nonlinear optimization, as is done for multilayer networks.

.. image:: /_static/screenshots/book1/ch17_non_linear_optimization.webp
   :alt: Non Linear Optimization demo window
   :width: 100%

**How to use it**

Use the slide bars to choose the number of neurons in the hidden layer and the difficulty of the function.

Select a Weight Inizialization method.

Click [Train] to train the Radial-basis network (orange function) on the blue function.

**Controls**

- Train (button)
- Initialization Method (menu)
