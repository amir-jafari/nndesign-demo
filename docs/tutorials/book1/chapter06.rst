Linear transformations
----------------------

Lets you define a linear transformation by choosing where two vectors are sent, then displays its eigenvectors: the directions that are only stretched or flipped, never rotated.

.. image:: /_static/screenshots/book1/ch06_linear_transformations.webp
   :alt: Linear transformations demo window
   :width: 100%

**How to use it**

Click in the top graph to create a vector. Move the mouse and click again to create the transformed vector. Repeat for a second vector.

These four vectors define a linear transformation. The eigenvectors of the transformation will be shown in the bottom graph. If the eigenvectors are complex they will not be shown.

Click in the bottom graph and move the mouse to see how other vectors are transformed.

**Controls**

- Clear (button)

.. _book1-ch06-eigenvector_game:

Eigenvector game
----------------

Builds intuition for eigenvectors by turning them into a search: a vector is an eigenvector of the hidden transformation when its image points in the same or the opposite direction.

.. image:: /_static/screenshots/book1/ch06_eigenvector_game.webp
   :alt: Eigenvector game demo window
   :width: 100%

**How to use it**

Your job is to find the two eigenvectors of an unknown transformation.

Click on the plot to draw a vector (in red) and see the transformed vector.

If their directions are the same or opposite, the first eigenvector will show up in green.

Repeat to find the second eigenvector.

**Controls**

- Number of Tries Left (slider)
- Restart (button)
